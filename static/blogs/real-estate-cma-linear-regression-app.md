I recently completed a class through coursera on creating AI models called [Supervised Machine Learning - Regression and Classification](https://www.coursera.org/learn/machine-learning?specialization=machine-learning-introduction). Having some real estate experience it dawned on me that linear regression is an improved way to create a CMA (competitive market analysis) reports than what I've done in the past. Also the instructor mentioned that in his opinion everyone in machine learning should write a linear regression algorithm at least once. Doing this with a real application in mind makes it more fun. So I created a simple app that will accept data on comparable properties to predict a price of a target home.

I learned to do CMAs about 30 years ago while working in real estate with my mother. The process we used was to find comparable sold properties that are as similar as possible to the target property. Ideally you find a half dozen or more, and then whittle that down to just the three best ones. Then we would price adjust each of those solds; accounting for how the home differs from the target property. For example if the sample home is smaller, we would increase it's price by some dollar amount per square foot. Or if it has a garage, but the target home doesn't, then we would subtract whatever we thought a garage is worth. This simple method worked well to check oneself when estimating a home price. It's the basis of coming up with a realistic price for a seller in an effort to help them price their property to sell quickly.

The above process is not without problems though. It relies on the estimator to have a rough idea of what the various features (such as square feet or garage) of a home are worth. And the costs of those features may need to be different depending on price range, home age, location, etc. Using a linear regression model removes the need for that experience. Another issue is that the manual process is time consuming. After gathering the data, all the math operations are performed manually which takes some time, and after a first pass it may be obvious tweaking the values is required. Using a linear regression model goes far to address both of these problems. Even with dozens of sample properties, the algorithms run in seconds. And the value of the features is calculated automatically. In the time I would do a CMA with three sample properties, I can complete a linear regression model based CMA with say 17 sample properties. And with bigger datasets, I become more confident in the algorithms ability to determine the worth of each feature.

Is a linear approach valid to calculate home prices? In general, home prices aren't linear because typically smaller houses sell for more per square foot due to higher demand which is drive by afforability. But when doing a CMA via any method you must select the most similar properties you can find. And if those are similar enough to the target house, then the error of using a linear model versus a more exact approach will be neglible. Again, the key is that the comparable properties are similar enough to the target. If that isn't true, then calculating a home price accurately becomes more difficult and beyond the abilities of a linear model.

So far the app has the following features:
- input file defines the target feature set, the target property data, and the comparable property data to keep everything in one place. 
- different input files can be loaded
- calculates a target price based on the comparable property data
- displays a graph for each feature showing how the line that calculates price sits within the sample dataset for that feature.
