I recently completed a class through coursera on creating AI models. It's called [Supervised Machine Learning - Regression and Classification](https://www.coursera.org/learn/machine-learning?specialization=machine-learning-introduction). Having some real estate experience it dawned on me that linear regression is an better way of what I used to do when creating CMA (competitive market analysis) reports. Also the instructor mentioned that everyone should write a linear regression algorithm at least once, and so I needed some application to make it more fun. So I ended up creating a simple app that will accept data on properties and use that data to predict a price of some target home.

The way I was taught to do a CMA 30 years ago is to first find sold properties that are as similar as possible to the target property. Ideally you would start with a half dozen or more, and then whittle that down to just the three best ones. Then price adjust each of those solds; accounting for how the home differs from the target property. For example if the sample home is smaller, increase it's price by some dollar amount per square foot. Or if it has a garage, but the target home doesn't, then subtract whatever you think a garage is worth.

This manual method works well if you have enough experience to come up with dollar amounts. But using a linear regression model removes the need for that experience. It also makes it easier to use more data. For example, in the time I would do a CMA with three sample properties, I can complete a linear regression model based CMA with say 17 sample properties.

Is a linear approach valid to calculate home prices? In general, home prices aren't linear. Typically smaller houses sell for more per square foot because the demand is higher due to affordability. But when doing a CMA via any method you must select the most similar properties you can find. If those are similar enough to the target house, then values are hopefully within a linear region of home prices, even if the bigger market isn't linear. Again, the key is that the sample properties are similar enough. If that isn't true, then calculating a home price accurately becomes more difficult and beyond the abilities of a linear model.
